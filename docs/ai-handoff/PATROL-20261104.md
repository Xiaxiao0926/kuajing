## 一、子体巡查结论

### 子体D — 线上部署（决定性发现）

**线上从未部署过 11-03 的 6 个提交。**

| 证据 | 值 |
|---|---|
| 线上 `DEPLOYED_COMMIT` | `23df9fa`（10-29 版本） |
| 线上主包 | `index-B__viPMM.js`（1,726,713 B） |
| 本地新包 | `index-C7uM2XeS.js`（1,686,750 B）→ 线上 404 |
| 新功能标记命中 | 项目卡点/候选预警/待办节点/openProjectDetail/returnLossCny 线上均为 **0**，本地均 ≥1 |

**根因**：`.github/workflows/deploy-kuajing.yml:78`
```yaml
if: github.event_name == 'workflow_dispatch' && github.ref == 'refs/heads/main'
```
push 只跑 `verify`（测试+构建+上传 artifact），`deploy` job 被 `if` 直接跳过，FTP 上传从未执行。不是部署失败，也不是部署中——是**从未触发**。

**次要因素**：Hostinger LiteSpeed 页面缓存 `max-age=604800`（7 天），即使上传成功，`/kuajing/` HTML 也可能继续引用旧 hash。
