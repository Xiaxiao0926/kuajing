# Ozon跨境选品分析面板

基于 Python + Streamlit 开发的 Ozon 热销产品数据分析工具，帮助中国卖家筛选适合在 Ozon 平台进行国内直发/RFBS/小批量测品的产品。

## 功能特点

- 📊 **数据概览**：总商品数、分类统计、价格带/重量段分布图表
- 🔍 **产品筛选**：支持多条件筛选、排序，展示各项评分和推荐等级
- 📦 **类目分析**：分析不同类目表现，找出优质赛道
- 💰 **利润测算**：自定义成本参数，实时计算预估利润
- 🎯 **单品详情**：查看单个商品的详细分析、风险提示和操作建议
- 📥 **数据导出**：支持导出分析结果为 Excel 文件

## 评分规则

综合评分 = 
- 市场需求分 * 0.25
- + 利润空间分 * 0.25  
- + 物流适配分 * 0.20
- + 合规安全分 * 0.15
- + 差异化机会分 * 0.10
- + 库存机会分 * 0.05
- - 竞争惩罚分

## 推荐等级

| 等级 | 说明 | 条件参考 |
|------|------|----------|
| **A类** | 直接可测 | 价格200-800₽、重量50-500g、评分≥4.3、广告占比<10%、利润率>20% |
| **B类** | 套装/改款后可测 | 市场需求强、物流适配好、可通过组合提升客单价 |
| **C类** | 供应链观察 | 市场需求存在、但利润/物流/竞争暂时不确定 |
| **D类** | 暂不建议 | 价格过低、重量/体积过大、合规风险高、广告占比过高 |

## 安装与运行

### 1. 安装依赖

```bash
cd ozon-product-analyzer
pip install -r requirements.txt
```

### 2. 运行应用

```bash
streamlit run app.py
```

### 3. 访问页面

运行后会自动打开浏览器，访问地址：`http://localhost:8501`

## 使用说明

1. **上传数据**：在侧边栏上传 Ozon 热销产品 Excel/CSV 文件
2. **设置参数**：配置汇率、采购成本、物流费用等参数
3. **筛选条件**：设置最低综合评分、推荐等级、价格/重量范围
4. **查看分析**：切换不同 Tab 查看总览、筛选表、类目分析、利润测算
5. **导出数据**：在导出页面选择字段并下载分析结果

## 自定义评分规则

如需修改评分规则，编辑 `app.py` 文件中的以下配置：

```python
# 评分权重配置（第36-43行）
SCORE_WEIGHTS = {
    'market_demand': 0.25,      # 市场需求分权重
    'profit_space': 0.25,       # 利润空间分权重
    'logistics_fit': 0.20,      # 物流适配分权重
    'compliance': 0.15,         # 合规安全分权重
    'differentiation': 0.10,    # 差异化机会分权重
    'inventory': 0.05,          # 库存机会分权重
}

# 合规风险关键词（第21-31行）
HIGH_RISK_KEYWORDS = ['фен', 'электрический', ...]  # 高风险关键词
LOW_RISK_KEYWORDS = ['органайзер', 'крючок', ...]   # 低风险关键词
```

## 技术栈

- **框架**: Streamlit 1.36.0
- **数据分析**: Pandas 2.2.x
- **可视化**: Plotly 5.22.x
- **Excel处理**: OpenPyXL、xlrd

## 注意事项

1. 支持 `.xlsx`、`.xls`、`.csv` 格式文件
2. 建议文件编码为 UTF-8
3. 字段名支持中英文自动识别
4. 首次上传可能需要等待数据处理
